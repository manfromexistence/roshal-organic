# **App Name**: Roshal Admin Dashboard

## Core Features:

- Overview Dashboard: Provide a quick overview of key metrics such as new orders, total products, and user statistics.
- Product Management: Enable adding, editing, and deleting organic product listings, including details, images, and pricing.
- Category Management: Allow administrators to create, organize, and manage product categories.
- Order Processing: View and manage customer orders, update statuses, and access order details.
- Payment Tracking: Monitor and manage payment transactions, statuses, and history for all orders.
- User Management: Manage user accounts, roles, and permissions within the dashboard.
- AI Marketing Content Generation: Utilize an AI tool to generate engaging marketing copy or product descriptions for marketing pages.

## Style Guidelines:

- Primary color: A rich, natural green (#248E46) to reflect organic and fresh themes, providing a solid anchor for interactive elements and branding.
- Background color: A very light, desaturated green (#EDF4EF) to create a clean, airy workspace that is easy on the eyes for extended use.
- Accent color: A vibrant lime green (#AEFC6B), approximately 30 degrees to the 'left' of the primary hue, used sparingly for calls to action or highlight key information to draw attention.
- Body and headline font: 'Inter', a grotesque-style sans-serif for its modern, neutral, and objective appearance, ensuring high readability across all dashboard elements.
- Employ a consistent set of clean, outline-style vector icons that align with the minimalistic and functional aesthetic of a management dashboard, as suggested by the example image.
- Implement a clear and responsive layout with a fixed left sidebar navigation, mirroring the structure observed in the user's reference image for intuitive access to all management sections.
- Incorporate subtle hover and click animations on navigation items and interactive buttons to provide immediate user feedback without being distracting.
